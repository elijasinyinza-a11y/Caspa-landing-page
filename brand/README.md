# CASPA™ brand assets

| File | What it is | Use |
| --- | --- | --- |
| `caspa-logo-original.png` | The logo as supplied, on white | Master copy; don't edit |
| `caspa-logo-full-transparent.png` | Full logo with tagline, transparent background | Print, documents, presentations |
| `caspa-lockup-transparent.png` | Mark and wordmark, no tagline, transparent | Source for the web sizes in `public/brand/` |
| `caspa-mark-transparent.png` | The three-bar mark alone, transparent | Small spaces, app icons |
| `caspa-mark.svg` | Vector redraw of the mark | Favicon and anywhere a sharp mark is needed |

Website copies live in `public/brand/` (header and footer lockup, WebP with PNG
fallback), plus `public/favicon.svg`, `public/apple-touch-icon.png` and
`public/og-image.png` (the link preview on social media and messaging apps).

## Rules for the website

- Use the logo on cream or white only. The top bar and the wordmark are navy,
  so the logo disappears on the navy sections. A reversed (light) version is
  needed before the logo can sit on navy.
- Keep the tagline out of the header and footer: it is unreadable at those sizes.
- The wordmark is a raster image. For very large uses (banners, signage), ask
  for the logo as an SVG or high-resolution vector file from its designer.
